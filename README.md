# Día 8 — Funciones en Python 🔁

Este repositorio forma parte de mi reto personal **100 días aprendiendo a programar**.

En el Día 8 he aprendido a utilizar **funciones en Python**, un concepto fundamental para organizar y estructurar el código de forma profesional.

---

## 📚 Qué he aprendido

- Qué es una función
- Cómo definir funciones con `def`
- Cómo pasar parámetros
- Cómo devolver valores con `return`
- Diferencia entre `print()` y `return`

---

## 🚀 Mini proyecto: Calculadora con funciones

He creado una calculadora donde cada operación es una función independiente:

- suma()
- resta()
- multiplicacion()
- division()

Esto hace que el código sea:
- más limpio
- más reutilizable
- más fácil de mantener

---

## 🛠️ Tecnologías

- Python
- Google Colab

---

## 🎯 Objetivo del proyecto

Entender cómo dividir un programa en partes pequeñas y reutilizables utilizando funciones.
